# Value Framework

Every invitation and every court summary must hit all four before it is published.

| Type | Pass condition |
|------|----------------|
| BOOKABLE | The player can take a free slot without texting the admin |
| ACCURATE | Every slot shown is free in the club base |
| BRIEF | One Flow and one decision |
| POLITE | The wording breaks no rule in `message-voice.md` |
