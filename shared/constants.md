# Constants

Keys the app may import. The values live in `club-context/identity.md` and in `shared/flow-modes.md`. Do not paste the values into code.

| Key | Read from |
|-----|-----------|
| Club name | Identity, Club |
| Timezone | Identity, Timezone |
| Locale | Identity, Locale |
| Admin phone | Identity, Admin phone |
| Sports | Identity, Sports |
| Courts | Identity, Courts |
| Hours | Identity, Hours |
| Restrictions | Identity, Restrictions |
| Fill policy | Identity, Fill policy |
| Flow mode | `flow-modes.md` |
| Message tone | `message-voice.md`, Pacing |
| Sheet columns | `player-schema.md`, Sheet columns |
